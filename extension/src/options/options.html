Amberfader

Classic-style remote for YouTube Music in Firefox.

Permissions

  • site access
  • nativeMessaging (desktop app)
  • tabHide (hide playback/controller tabs)

Permissions can be revoked any time in about:addons. Amberfader never asks for cookies, history, or all-URLs access.

Desktop app (native mode)

Native mode is off.

Native mode opens a hidden controller tab that owns the connection to the desktop app. If the controller tab was closed, the desktop app cannot recover it — press Reconnect here.

Phase 0 probes

Run diagnostic probes inside the selected YouTube Music tab. Output is sanitized (structure, attribute names, hosts only).
